Выгрузка Telegram в markdown, который не стыдно отдать ИИ

Отметьте нужные чаты и форум-топики: tgsum сохранит каждый в ровный .md без служебного мусора. Всё остаётся на этом компьютере.

или перетащите файл или папку выгрузки в окно ⌘O
Как получить result.json
  1. Откройте Telegram Desktop → Настройки → Продвинутые настройки.
  2. Нажмите Экспорт данных из Telegram (Export Telegram data).
  3. Формат — Машиночитаемый JSON; медиа можно не включать.
  4. После экспорта в папке появится result.json — перетащите его сюда.
  • без сетивсё остаётся на компьютере
  • без ключейни API, ни аккаунтов
  • до пары гигабайтJSON читается потоком
