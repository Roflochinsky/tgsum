Работа в фоне

Когда сбор включён, закрытие окна оставляет TGSUM работать. Чтобы вернуться, откройте TGSUM через меню приложений — появится то же окно.

Проверяю состояние…

При следующем входе приложение запустится без окна и возобновит включённый сбор. Выключение автозапуска сохраняет историю и не останавливает текущий процесс.

Завершение останавливает процесс. Настройки и история остаются; включённый сбор возобновится при следующем запуске.

Как сохранить переписку

Откройте result.json, отметьте чаты и выберите папку для готовых файлов. Разовый экспорт сохраняет текст в Markdown (.md); исходный архив остаётся на месте.

Файл Markdown можно открыть в текстовом редакторе или приложить к сообщению. Для разового экспорта создавать проект и подключать ИИ не нужно. Очистка чувствительных данных и вложения настраиваются отдельно в проекте.

Начните с архива Telegram

  1. В Telegram Desktop откройте нужный чат → меню → «Экспорт истории чата».
  2. Выберите машиночитаемый JSON и дождитесь окончания экспорта.
  3. На главном экране нажмите «Выбрать result.json» и отметьте нужные чаты или темы.

Подходит экспорт одного чата или всех данных. HTML-экспорт не подходит. Для пакета с вложениями сохраните result.json вместе с папками фотографий и документов.

Повторная обработка и место сохранения

В разделе «Проекты» можно сохранить выбор чатов и настроить очистку. В блоке «Собрать выбранные чаты в папку» выберите папку с экспортом и папку результата. Новые выгрузки Telegram нужно класть во входную папку; автоматическое обновление работает, пока TGSUM открыт.

Разовый экспорт сохраняется в папку, указанную на шаге «Сохранение». Путь пакета показан в проекте рядом с кнопкой открытия. Исходный архив не перемещается.
