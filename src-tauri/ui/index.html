Telegram-выгрузка → чистые .md для чата с ИИ

Выберите чаты и форум-топики — tgsum сохранит каждый в аккуратный Markdown. Локально: без API, без сети, без облака.

Как получить result.json
  1. Откройте Telegram Desktop → Настройки → Продвинутые настройки.
  2. Нажмите Экспорт данных из Telegram (Export Telegram data).
  3. Формат — Машиночитаемый JSON; медиа можно не включать.
  4. После экспорта в папке появится result.json — перетащите его сюда.
